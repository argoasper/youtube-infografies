## Descripció

Le cuentas a Claude Code una decisión importante y siete consejeros la debaten en tres rondas: Bezos, Buffett, Hormozi, Paul Graham, Gary Vaynerchuk, Dan Martell y Gino Wickman. Al final te da un veredicto con nota.

Es Roast Room, una skill gratis y de código abierto. Ojo: no son ellos, son simulaciones hechas con lo que cada uno ha publicado (libros, cartas, entrevistas).

Lo malo: necesitas Claude Code (de pago) y hace unas 20 consultas a la vez, así que gasta.

⚙️ El comando para instalarla:
git clone https://github.com/nateherkai/roast-room.git

Pasos: entra en la carpeta, arranca la sala con «npm start» (necesitas Node.js 20 o más), abre Claude Code en esa carpeta y escribe «/roast-room» y tu decisión.
