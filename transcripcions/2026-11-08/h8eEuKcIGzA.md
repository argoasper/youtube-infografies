## Descripció

🎁 Consigue GRATIS la guía paso a paso para usar otros modelos en Claude Code con FreeLLMAPI en el vídeo completo enlazado aquí

Claude Code y Claude son dos piezas distintas. Claude Code es el entorno con el que trabajas, y Claude, el modelo que ejecuta tus tareas, y puedes cambiar el modelo sin tocar el entorno.

Con FreeLLMAPI mantienes Claude Code y cambias solo el modelo por otros de Gemini, Groq u OpenRouter. Si configuras varios, el sistema salta entre ellos al llegar al límite y la tarea sigue.

Así reservas Claude para los trabajos complejos y usas un modelo gratis o mucho más barato para las tareas sencillas o las que consumen mucho contexto, sin cambiar tu forma de trabajar.

La experiencia en Claude Code es prácticamente la misma, y ganas un entorno donde eliges el modelo según la tarea: el más potente cuando hace falta y uno gratis o más barato para lo demás.
