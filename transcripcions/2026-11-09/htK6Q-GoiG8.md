## Descripció

🎁 Consigue GRATIS la guía paso a paso para darle memoria a Claude Code con claude-mem en el vídeo completo enlazado aquí

Si trabajas varios días en un proyecto con Claude Code, claude-mem le da memoria persistente para que cada conversación nueva arranque con lo importante, sin explicarle todo desde cero.

Es un plugin open source que usa los hooks de Claude Code para detectar cambios, decisiones y acciones importantes mientras trabajas, y los convierte en observaciones que consulta después.

Para probarlo construí una aplicación en la que tomamos varias decisiones, cerré la conversación y, en una sesión nueva, Claude recuperó esas decisiones y siguió construyendo desde ahí.

Por tanto, carga primero lo importante y busca el detalle cuando se lo pides, por ejemplo cómo tomaste una decisión, y trabajar semanas en un mismo proyecto se vuelve mucho más coherente.
