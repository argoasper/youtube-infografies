## Descripció

🎁 Consigue GRATIS la guía paso a paso para instalar Frontend Slides en Claude Code, con los prompts del vídeo, en el vídeo completo enlazado aquí

Claude Code puede crear presentaciones con diseños personalizados, gráficos animados y elementos interactivos para usar mientras presentas, con Frontend Slides, una skill de código abierto.

La skill genera cada presentación con HTML, CSS y JavaScript a partir de lo que le cuentas, y al trabajar con código personalizas mucho más el diseño y el comportamiento de cada diapositiva.

Se instala dándole a Claude Code el enlace del repositorio. Para probarla le pedí 6 diapositivas sobre cómo usan la IA las empresas, y me enseñó 3 direcciones visuales para elegir.

El resultado trae elementos animados, diagramas y componentes interactivos, y puede rediseñar un PowerPoint que ya tengas. Todo lo cambias hablando con el agente, sin otra herramienta.
