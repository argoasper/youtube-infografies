## Descripció

🎁 Consigue GRATIS la guía paso a paso para instalar el plugin de Expo en Claude Code y crear tu app, en el vídeo completo enlazado aquí

Expo es una herramienta de código abierto para crear apps con el mismo código para iPhone y Android, y su plugin oficial para Claude Code incorpora 24 skills preparadas por su propio equipo.

Esas skills le dan a Claude instrucciones y buenas prácticas de diseño, navegación, APIs y animaciones, y el propio agente detecta cuándo usar cada una según lo que le pides en cada momento.

Para probarlo le pedí una app de nutrición inspirada en Cal AI, y en unas dos horas y media Claude hizo un prototipo con registro de comidas, plan de alimentación, progreso y coach de IA.

Con las skills de diseño la app quedó mucho más cuidada, y un MCP le da la documentación de Expo. Por tanto, Claude Code desarrolla, diseña y mejora apps con las buenas prácticas de Expo.
