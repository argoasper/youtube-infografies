## Descripció

🎁 Consigue GRATIS la guía paso a paso para instalar Pstack en Claude Code y usar Arena, TDD y Create Verification Skill, en el vídeo completo enlazado aquí

Arena, TDD y Create Verification Skill son 3 skills de código abierto de Pstack que usas en Claude Code para desarrollar mejores apps y comprobar que funciona lo que construye el agente.

Arena pone a varios agentes con el mismo problema, cada uno propone su solución y te quedas con las mejores ideas. Con TDD, primero se crea la prueba del comportamiento que quieres.

Por ejemplo, en una lista de espera para una app de reservas, con TDD escribes la prueba de avisar al siguiente cuando alguien cancela, y Claude programa hasta que pasa y la conserva.

Create Verification Skill crea una skill para que Claude arranque tu app, la use como usuario y recoja evidencias. Así comparas soluciones, programas con pruebas y compruebas que funciona.
