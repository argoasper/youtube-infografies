## Descripció

🎁 Consigue GRATIS la guía paso a paso para instalar Taste Skill en Claude Code, con los prompts de la prueba con y sin la skill, en el vídeo completo enlazado aquí

Cuando creas webs con Claude Code es habitual acabar con las mismas estructuras, los mismos componentes y diseños muy parecidos entre sí, sea cual sea el tipo de proyecto que desarrollas.

Taste Skill es una skill de código abierto con instrucciones, referencias visuales y herramientas para que Claude tome mejores decisiones de diseño cuando construye una página web.

Dos sesiones de Claude Code hicieron la misma web de una empresa ficticia, una con la skill y otra sin ella, y la de Taste Skill salió con más identidad, con animaciones y adaptada al móvil.

Además, la skill permite a Claude abrir la web en el navegador, hacer capturas y revisarla en distintos tamaños de pantalla, así que comprueba su propio trabajo antes de darlo por terminado.
