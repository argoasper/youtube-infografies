## Descripció

🎁 Consigue GRATIS la guía paso a paso para activar Code Mode en Claude Code, con las pruebas publicadas y prompts para probarlo en tu proyecto, en el vídeo completo enlazado aquí

Code Mode es una función experimental de Claude Code en la que Claude escribe pequeños programas en JavaScript que usan sus herramientas y le devuelven solo los datos que necesita.

Normalmente, al investigar un proyecto, Claude recorre muchos archivos y mete cada resultado en la ventana de contexto. Con Code Mode lo procesa aparte y tú sigues usando Claude Code igual.

En una prueba publicada con FastAPI, un repositorio de más de 1.200 archivos, Claude leyó unos 93.000 tokens en lugar de más de 250.000, y el contexto acabó ocupando un 37 % menos.

Su ventaja está en el contexto más que en la velocidad, porque preparar cada programa lleva su trabajo. Así Claude aprovecha mejor sus herramientas y guarda más espacio para tu proyecto.
